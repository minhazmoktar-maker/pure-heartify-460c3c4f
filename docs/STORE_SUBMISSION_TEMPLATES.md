# Heartify — Store Submission Templates

This file is the repository-side scaffolding for App Store and Google Play
submission. It contains ready-to-paste text and files that can be produced
without a Mac/Android Studio, and clearly separates each item into one of:

- **Repo** — implemented in this repository, ready to ship.
- **Console** — must be entered in App Store Connect / Play Console UI.
- **Device** — must be verified on a physical device before submission.

Companion docs:
- `docs/STORE_LISTING.md` — long-form marketing copy.
- `public/.well-known/apple-app-site-association` — Universal Links.
- `public/.well-known/assetlinks.json` — Android App Links.

---

## 2. iOS `Info.plist` usage strings

**Status:** Console/Xcode. Paste into `ios/App/App/Info.plist` before
archive.

```xml
<key>NSUserNotificationsUsageDescription</key>
<string>Heartify sends prayer time reminders and streak alerts. You can disable them anytime in Settings.</string>
<key>NSLocationWhenInUseUsageDescription</key>
<string>Heartify uses your location only to calculate accurate prayer times and Qibla direction. Location is never sold or shared.</string>
```

Only add camera/microphone entries if a build actually links those APIs —
Heartify does not, so omit them or Apple review will flag the discrepancy.

## 4. Universal Links / App Links — status

**Repo:** structure and paths are correct. Actual bundle / team ID /
signing SHA-256 fingerprint substitution is **Console** work.

- `public/.well-known/apple-app-site-association` — replace `TEAMID` with
  the Apple Team ID from App Store Connect → Membership.
- `public/.well-known/assetlinks.json` — replace the two SHA-256 fingerprint
  placeholders with:
  1. The upload key fingerprint from
     `keytool -list -v -keystore upload-keystore.jks`.
  2. The Play App Signing certificate fingerprint from
     Play Console → Setup → App integrity → App signing.

Both files are already served over HTTPS by Lovable hosting with
`Content-Type: application/json` — no additional CDN configuration required.
